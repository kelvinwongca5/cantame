# Cántame

A song-first, Once-style daily Spanish reading program for Mexican-American heritage speakers.

- `index.html` — interactive tablet demo of one 15-minute session (Unit 1, session 12, *Los pollitos dicen*), with a synthesized hummed melody.
- `concept.html` — the research-backed program concept.
- `canciones.html` — the *cancionero*: 21 traditional Mexican songs and rhymes for singing with a child. Spanish lyrics with English glosses, cultural notes, hand games, key words, read-aloud in a Mexican Spanish voice, hummed tunes for *Los pollitos dicen* and *Estrellita*, a big-type sing-along mode, and a bilingual (English / Spanish) tutorial for parents.
- `guide.html` — a step-by-step tutorial for the adult. One screen at a time, plain language, with drawings. Three practices first (the tune, the slow beat, the quiet), which you have to actually do before you can move on, then the six parts of a session. English or Spanish.

Static site; deploys to GitHub Pages from the `main` branch root. No build step.

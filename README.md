# Cántame

A song-first, Once-style daily Spanish reading program for Mexican-American heritage speakers.

- `index.html` — interactive tablet demo of one 15-minute session (Unit 1, session 12, *Los pollitos dicen*), with a synthesized hummed melody.
- `concept.html` — the research-backed program concept.
- `guide.html` — an elaborate walkthrough for the adult running a session: all six steps with the Spanish script glossed in English, a rehearsal lab for the tune, the walking pulse and the scheduled silence, a control reference, troubleshooting, and a glossary. Switchable English/Español.

Static site; deploys to GitHub Pages from the `main` branch root. No build step.
